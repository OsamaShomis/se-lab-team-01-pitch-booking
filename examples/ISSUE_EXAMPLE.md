# مثال Issue

## User Story

بصفتي طالباً،  
أريد إضافة موعد نهائي للمهمة،  
حتى أتمكن من ترتيب أولويات الواجبات.

## Acceptance Criteria

- [ ] Given أن الطالب سجل الدخول، When يضيف مهمة بموعد صحيح، Then تظهر المهمة في قائمته.
- [ ] Given أن العنوان فارغ، When يضغط حفظ، Then تظهر رسالة أن العنوان مطلوب.
- [ ] لا يتم إنشاء المهمة مرتين عند الضغط المتكرر.

## Edge Cases

- تاريخ في الماضي.
- عنوان يحتوي على مسافات فقط.
- انقطاع الاتصال أثناء الحفظ.
