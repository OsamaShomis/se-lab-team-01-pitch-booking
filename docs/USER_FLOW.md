## 1. تدفق اللاعب / كابتن الفريق (Player Flow)

```mermaid
flowchart TD
    A([يفتح المنصة]) --> B{هل لديه حساب؟}
    B -- لا --> C[ينشئ حساباً جديداً\nالاسم + البريد + كلمة المرور]
    B -- نعم --> D[يسجّل الدخول]
    C --> D
    D --> E[يتصفح قائمة الملاعب\nالاسم / الموقع / نوع الأرضية / السعر]
    E --> F[يختار ملعباً محدداً]
    F --> G[يختار تاريخ الحجز]
    G --> H[يرى جدول الساعات\nمتاح — محجوز]
    H --> I{الفترة المطلوبة متاحة؟}
    I -- لا --> H
    I -- نعم --> J[يضغط على الفترة ويؤكد الحجز]
    J --> K{هل نجح الحجز؟}
    K -- نعم --> L([تأكيد الحجز\nرقم الحجز + التفاصيل])
    K -- لا Race Condition --> M([عذراً، تم حجزها للتو\nأعد المحاولة])
    L --> N{يريد إلغاء الحجز؟}
    N -- لا --> O([انتهى])
    N -- نعم --> P{هل تبقى أكثر من ساعتين؟}
    P -- نعم --> Q([تم الإلغاء بنجاح])
    P -- لا --> R([لا يمكن الإلغاء\nأقل من ساعتين على الموعد])
```

## 2. تدفق صاحب الملعب / المسؤول (Venue Owner Flow)

```mermaid
flowchart TD
    A([يفتح المنصة]) --> B[يسجّل الدخول بحساب المسؤول]
    B --> C[يدخل لوحة التحكم Dashboard]
    C --> D[يرى جدول حجوزات اليوم\nبحسب الفترات الزمنية]
    D --> E{هل يريد اتخاذ إجراء؟}
    E -- تأكيد حضور --> F([تأكيد الحجز — حضر اللاعب])
    E -- إلغاء حجز --> G([إلغاء الحجز — الفترة تصبح متاحة])
    E -- لا --> H([مشاهدة فقط])
    F --> D
    G --> D
```

## 3. Business Flow — تدفق العملية الكاملة من البداية للنهاية

```mermaid
flowchart LR
    subgraph لاعب
        A1[فتح المنصة] --> A2[تصفح الملاعب]
        A2 --> A3[اختيار ملعب وتاريخ]
        A3 --> A4[اختيار فترة متاحة]
        A4 --> A5[تأكيد الحجز]
    end

    subgraph النظام
        B1[التحقق من صحة البيانات]
        B2[فحص التعارض Race Condition Lock]
        B3[تسجيل الحجز في قاعدة البيانات]
        B4[تحديث جدول الساعات فوراً]
    end

    subgraph صاحب_الملعب
        C1[رؤية الحجز في Dashboard]
        C2[تأكيد الحضور أو الإلغاء]
    end

    A5 --> B1 --> B2 --> B3 --> B4 --> C1 --> C2
```

## 4. حالات الحافة في التدفق (Edge Cases in Flow)

| الحالة | سلوك النظام |
|---|---|
| **لاعب غير مسجّل يحاول الحجز** | يُعاد توجيهه لصفحة تسجيل الدخول تلقائياً |
| **فترة محجوزة للتو (Race Condition)** | رسالة خطأ فورية، الفترة تُحذف من الاختيار |
| **محاولة حجز في تاريخ/وقت مضى** | الأزرار معطّلة، لا يمكن الاختيار |
| **إلغاء متأخر (أقل من ساعتين)** | رفض الإلغاء مع توضيح سبب الرفض |
| **انقطاع الإنترنت أثناء الحجز** | لا يُسجَّل حجز معلق، تنبيه بإعادة المحاولة |
