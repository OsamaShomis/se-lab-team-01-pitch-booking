## 4. إرشادات وقواعد الفريق (Team Rules)
1. **يُمنع التعديل المباشر على فرع `main`:** جميع التعديلات تتم عبر فروع مستقلة.
2. **فصل الأدوار:** لا يقوم كاتب الـ Pull Request بمراجعة أو دمج عمله بنفسه.
3. **توثيق الذكاء الاصطناعي:** أي مساعدة برمجية يتم تسجيلها وتوضيح التعديل البشري عليها في `AI_Log.md`.
